## Карта документов

### [USER-GUIDE.md](USER-GUIDE.md) — руководство пользователя
Требования · установка (ярлык, `setup.py`, вручную) · виртуальное аудиоустройство
для Windows/macOS · запуск · порядок работы по шагам · проекты · гайды и
библиотека · язык интервью · промпты и доп. инструкции · что сохраняется ·
отчёт · сброс · проверка без интервью · устранение неполадок.

### [CONFIGURATION.md](CONFIGURATION.md) — справочник по конфигурации
Каждый ключ всех восьми блоков с дефолтом и пояснением, за что он платит. Рецепты:
экономия VRAM, Apple Silicon, настройка задержки транскрипта.

### [ARCHITECTURE.md](ARCHITECTURE.md) — устройство системы
Компоненты · поток данных и модель конкурентности · нарезка реплик · запись
аудиодорожки · восстановление после падения · выбор ASR-модели по языку · движок
покрытия · контракт с LLM · REST и WS · данные на диске · **точки расширения** ·
**инварианты, которые нельзя ломать**.

### [API.md](API.md) — REST и WebSocket
Все эндпоинты с телами запросов, коды ошибок, модель безопасности, полный список
событий WebSocket.

### [DATA-FORMATS.md](DATA-FORMATS.md) — форматы на диске
Раскладка папок · гарантии записи (append+fsync / атомарная перезапись /
перегенерация) · каждый файл сессии с примером и разбором полей · `project.json` ·
библиотека гайдов · `prompts.json` · восстановление после падения.

### [TESTING.md](TESTING.md) — тестирование
Автотесты, ручные чек-листы, критерии приёмки.
