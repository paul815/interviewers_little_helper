# Interviewer's Little Helper

**Локальный второй пилот для качественных интервью по Zoom.**
Живой транскрипт с разделением говорящих, чеклист покрытия тем и подсказки от LLM —
в окне поверх созвона. Ни один байт не уходит с вашей машины.

## Что это

Вы ведёте глубинное интервью и одновременно должны: слушать, задавать хорошие
follow-up'ы, помнить весь гайд, следить за временем и записывать яркие цитаты.
Что-то из этого неизбежно проваливается.

ILH берёт на себя механическую часть. Он слушает два аудиоканала — ваш микрофон
и звук из Zoom, — расшифровывает их в раздельные транскрипты, раз в четыре
минуты сравнивает разговор с гайдом через локальную LLM и показывает справа от
созвона: что уже раскрыто, что вы пропустили, что стоит уточнить прямо сейчас и
успеваете ли вы по времени.

Всё считается на вашем железе. ASR — Parakeet TDT, LLM — Ollama, веб-сервер
слушает только `127.0.0.1`. Сеть нужна ровно один раз: скачать веса при установке.

## Что он умеет

| | |
|---|---|
| 🎙 **Раздельные каналы** | Микрофон = интервьюер, системный звук = респондент. Разделение на уровне ОС, а не диаризацией — значит, без ошибок |
| ⚡ **Живой транскрипт** | Потоковый Silero VAD + Parakeet TDT: реплика уходит в ASR через 0.65–0.80 с после того, как человек договорил, а не пачкой раз в полминуты |
| ✅ **Покрытие тем** | `covered` / `partial` / `not_covered` по каждому пункту гайда, с цитатами-доказательствами |
| 💡 **Подсказки** | Непокрытые темы с готовыми формулировками вопросов + пробинг-вопросы по свежим репликам респондента |
| ⏱ **Темп** | Успеваете ли пройти гайд за отведённое время |
| 🚩 **Флаги и комментарии** | F5 — отметить момент; комментарий сохраняется с таймкодом и с тем вопросом гайда, под которым написан |
| 📁 **Проекты** | Серия интервью по одному гайду: свой пресет, своя папка, сводное покрытие по всей серии |
| 📄 **Отчёт** | После «Стоп»: резюме, тезисы по темам, непокрытое, отмеченные моменты |
| 🎧 **Переслушать** | Расшифровка прошлого интервью вместе с записью: клик по реплике перематывает плеер |
| 🔒 **Приватность** | Ноль внешних запросов, ноль телеметрии, ноль API-ключей |

## Быстрый старт

**Требования:** Python 3.11+, 32 GB RAM, наушники (обязательно — иначе микрофон
подхватит респондента из колонок). Windows 10 22H2+ / macOS 14+ / Linux.

```bash
git clone <repo-url> && cd interviewers_little_helper
python setup.py
```

`setup.py` создаёт `.venv`, ставит зависимости под вашу ОС, качает веса ASR и
предлагает доставить Ollama с моделью. На Windows можно вместо этого просто
кликнуть **`Launch ILH.lnk`** — при первом запуске он сам вызовет установку, а
дальше будет просто поднимать приложение.

```bash
source .venv/bin/activate     # Windows: .venv\Scripts\Activate.ps1
python -m app.main
```

Дальше: выбрать микрофон и системный звук в **⚙**, вставить гайд во вкладке
**«Настройки проекта»**, нажать **Старт**.

Подробная установка, настройка виртуального аудиоустройства и полный порядок
работы — в **[руководстве пользователя](docs/USER-GUIDE.md)**.

## Как это устроено

```
Микрофон ─────┐                                          ┌──▶ Транскрипт (JSONL + MD)
              ├─▶ VAD ─▶ реплика ─▶ Parakeet ─▶ сегмент ─┤
Звук Zoom ────┘                                          └──▶ раз в 4 мин ─▶ Ollama
                                                                                │
                          UI (окно поверх Zoom) ◀── WebSocket ◀── покрытие + подсказки
```

Реплика — единица обработки: VAD закрывает её через 0.6 с тишины и сразу
отправляет в ASR. Parakeet в int8 работает на CPU, поэтому вся видеопамять
достаётся LLM. Состояние покрытия монотонно (статус только повышается), а против
дрейфа каждый 4-й цикл перепроверяет последние минуты, и на «Стоп» весь
транскрипт прогоняется целиком.

Полный разбор — в **[архитектуре](docs/ARCHITECTURE.md)**.

## Приватность

Это главное свойство, а не бонус:

- **Аудио, транскрипт и гайд не покидают машину.** ASR и LLM локальные, API-ключей нет вообще.
- **Сервер слушает только `127.0.0.1`** и вдобавок сверяет заголовки `Host` и
  `Origin` — WebSocket не подчиняется CORS, и без этой проверки открытая во время
  интервью вкладка могла бы читать живой транскрипт.
- **Фронтенд не загружает внешних ресурсов** — ни шрифтов, ни CDN, ни аналитики.
- **Веса скачиваются с закреплённого коммита**, версии зависимостей зафиксированы
  точно: обновление на машине исследователя не происходит само.
- **Данные лежат открытым текстом и не удаляются сами.** Политики хранения нет
  осознанно — удалять исследовательские материалы за исследователя приложение не
  должно. Не нужна запись голоса — `storage.save_audio: false`.

## Ограничения

- **Языки.** Parakeet — 25 европейских языков, GigaAM — русский с пунктуацией. Для
  японского, китайского, корейского, арабского приложение само переключится на Whisper.
- **Словарь терминов** работает только с Whisper: Parakeet не поддерживает подсказку промптом.
- **Задержка** конвейера — 0.65–0.80 с от конца реплики до строки, плюс время
  декодирования на вашем железе (померить: `python -m tools.bench_asr запись.wav`).
- **Эхоподавления нет** — работайте в наушниках.
- **Always-on-top** только в режиме окна; с `--browser` вкладка спрячется за Zoom.
- **Гайд до ~40 тем** — весь гайд, состояние и дельта должны помещаться в контекст LLM.

## Разработка

```bash
pip install -r requirements-dev.txt
pytest                                          # юнит + API + E2E на фейковых ASR/LLM
ruff check .

```

CI гоняет тот же набор на Linux, macOS и Windows. Точки расширения (новый
ASR-бэкенд, свой источник событий речи, не-Ollama LLM) описаны в
